# Teil IV – Aus einzelnen Skills betriebliche Praxis machen

Ein brauchbarer Entwurf ist ein guter Anfang. Eine verlässliche Arbeitsweise entsteht daraus, wenn auch die Übergaben, Zuständigkeiten und Rückmeldungen funktionieren. Wer prüft eine Gesprächszusammenfassung? Welche ihrer Angaben darf in ein Angebot eingehen? Was geschieht, wenn sich später eine Voraussetzung ändert? Diese Fragen verbinden die einzelnen Praxisbausteine mit dem Unternehmen.

In diesem Teil führen wir das Lindenwerk-Beispiel weiter. Wir betrachten eine begrenzte Folge von Arbeitsschritten, die Einführung im Team und eine nachvollziehbare Nutzenrechnung. Zum Schluss entsteht ein Plan für die ersten 30 Tage. Sie können ihn auf einen internen Ablauf ebenso anwenden wie auf eine Leistung im Kundenmandat.

Dabei wächst die Technik nur so weit, wie die Arbeit es verlangt. Eine manuelle Übergabe kann für den ersten Einsatz ausreichen. Wenn sie sich bewährt und regelmäßig Aufwand verursacht, lässt sich gezielt untersuchen, ob eine technische Verbindung hilft. Der Maßstab bleibt das überprüfbare Ergebnis.
