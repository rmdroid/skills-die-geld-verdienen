# Teil II – Abläufe auswählen und Skills anpassen

Im ersten Teil haben Sie einen Skill als Arbeitsmittel kennengelernt und seinen Einsatz vorbereitet. Jetzt betrachten wir die Entscheidungen hinter diesem Arbeitsmittel. Welche Aufgabe ist geeignet? Welche Regeln muss die Anleitung enthalten? Was darf übernommen werden, was muss an das Unternehmen angepasst werden und wie lässt sich eine Verbesserung nachweisen?

Die folgenden Kapitel führen von einer alltäglichen Reibung zu einem begrenzten, prüfbaren Verfahren. Als Ergebnis entsteht eine fachliche Grundlage für die zwölf Praxis-Skills in Teil III. Die vollständigen Skill-Dateien bleiben in den separaten Begleitmaterialien.
