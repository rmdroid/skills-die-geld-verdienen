# Hinweise zur Website

Diese Website verwendet keine von uns eingebundenen Analyse- oder Werbedienste und keine extern geladenen Schriftarten. Ihre Eingabe für den Lesebereich wird lokal im Browser geprüft. Der Freigabestatus wird nur für die laufende Browser-Sitzung in sessionStorage gespeichert.

Die Bereitstellung erfolgt über GitHub Pages. Dabei verarbeitet GitHub technische Zugriffsdaten nach seiner [Datenschutzerklärung](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement). Externe Links führen zu den jeweiligen Anbietern; die Verbindung wird beim Öffnen des Links hergestellt.

Verantwortlich für dieses Angebot ist Robert Meyer. Kontakt und Anschrift finden Sie im [Impressum](/impressum). Diese Hinweise sind vor der Veröffentlichung unter einer eigenen Domain an deren tatsächlichen Hostingbetrieb anzupassen.
